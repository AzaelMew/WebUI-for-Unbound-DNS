Manual blocked domains

Use domain names, not URLs, IPs or wildcards. Entries covered by an allowlist exception are removed from manual blocks.

Allowlist exceptions

An exception allows this domain and all its children, including beneath a blocked parent. Other DNS configuration is not edited.

HTTPS subscriptions

No lists are enabled by default. Add a raw-text HTTPS URL, refresh it explicitly, then enable the cached list. Refreshing an enabled list applies its new rules. A failed or empty refresh keeps its last good cache and running DNS rules.

Supported formats, safety limits & DNS filtering limits

Supports UTF-8 plain domains, blocking hosts entries (0.0.0.0, 127.0.0.1, ::, ::1), and simple ||domain^ rules. Not a full Adblock parser: exceptions, options, regexes and cosmetic rules are reported as unsupported; use this page’s allowlist instead.

Limits: 20 MiB per download, 300,000 unique domains across all cached lists and manual rules, 25 subscriptions. Only public HTTPS on port 443; private destinations, credentials and unsafe redirects are refused. There is no automatic refresh schedule.

DNS filtering cannot remove same-domain ads or page elements. Clients using another resolver or custom DoH can bypass it. DNS/client caches may delay visible changes. Filters only override this manager’s rules; unrelated local DNS policies remain intact.
